# システム構成・カスタマイズ・他PC移行ガイド

このドキュメントでは、**OCC-Web (Orlaco EMOS Camera Configurator GUI)** のシステム全体の構造、各ファイルの役割、修正方法、および他のPCへのコピー手順を分かりやすく解説します。

---

## 1. 他のPCへのコピー＆実行手順（ポータブル利用）

このツールは、フォルダを丸ごと別のWindows PCにコピーするだけで動作するよう設計されています。

### コピー手順

1. **フォルダごとコピー**
   `occ-web` フォルダ（`.venv` は除外しても自動再生成されます）をUSBメモリ等で目的のPCにコピーします。

2. **前提条件（コピー先PC）**
   - **OS**: Windows 10 または Windows 11 (64bit)
   - **Python**: Python 3.10 以上がインストールされていること ([Python公式サイト](https://www.python.org/downloads/))
     - ※ インストーラー実行時に **「Add python.exe to PATH」** にチェックを入れてください。
   - **LAN接続**: Orlaco EMOS カメラと同一ネットワークに有線LAN等で接続されていること。

3. **実行**
   `start.bat` をダブルクリックします。
   - 初回起動時に自動で仮想環境を作成し、必要なライブラリ（Flask, OpenCVなど）を自動インストールします。
   - インストール完了後、Webブラウザ（`http://localhost:5000`）が自動で開きます。

## 2. システム全体のファイル構成と役割

```
occ-web/
│
├── start.bat                   ★ 起動用バッチファイル（ダブルクリックで起動）
│
└── system/                     【システム内部フォルダ】
    ├── README.md               ★ 全体概要・クイックスタート
    ├── STRUCTURE_AND_CUSTOMIZE.md ★ 本ドキュメント（構成と修正ガイド）
    │
    ├── backend/                【バックエンド (Python)】
    │   ├── app.py              ★ Webサーバー & REST API エンドポイント
    │   ├── occ_wrapper.py      ★ occ.exe を呼び出すラッパー処理
    │   ├── streamer.py         ★ RTP映像受信 & ブラウザ向けリアルタイム配信処理
    │   ├── net_utils.py        ★ ネットワーク検出処理
    │   ├── occ.exe             ★ Orlacoカメラ通信用バイナリ (配置済み)
    │   └── requirements.txt    ★ Python依存パッケージ一覧
    │
    └── frontend/               【フロントエンド (HTML / CSS / JavaScript)】
        ├── index.html          ★ Web画面の構造（レイアウト・タブ・モーダル）
        ├── style.css           ★ デザイン・ダークテーマ・レスポンシブスタイル
        └── app.js              ★ 画面操作ロジック（API通信・状態管理・プリセット）
```

## 3. 各ファイルの詳細と「どこをどう修正すればいいか」

### ① `backend/app.py` （Webサーバー & API）
- **機能**: Flask による HTTP REST API サーバー。フロントエンドからのリクエスト（カメラ発見、レジスタ読み書き、ROI設定、映像ストリーム）を受け取り、対応する処理を呼び出します。
- **よくある修正ポイント**:
  - ポート番号を変更したい場合: 最下部の `app.run(port=5000)` を `port=8080` などに変更。
  - 新しいAPIエンドポイントを追加したい場合: `@app.route("/api/...")` 関数を追加。

### ② `backend/occ_wrapper.py` （occ.exe ラッパー）
- **機能**: `occ.exe` をコマンドラインからサブプロセスとして実行し、標準出力を正規表現でパースしてPythonの辞書/JSONに変換します。
- **よくある修正ポイント**:
  - `occ.exe` のコマンドライン引数仕様が変わった場合: 各関数（`discover_cameras`, `read_registers`, `write_roi` など）内の引数リストを調整。
  - レジスタ番号の対応表を追加・修正したい場合: 先頭の `REGISTER_NAMES` 辞書にレジスタ番号と名前を追加。

### ③ `backend/streamer.py` （映像ストリーミング）
- **機能**: カメラから送信される RTP UDPパケット（H.264 / MJPEG）をOpenCVでデコードし、ブラウザ向けにMJPEGストリーム（`/api/video_feed`）として配信します。
- **よくある修正ポイント**:
  - デフォルトの受信ポートを変更したい場合: `VideoStreamer.__init__` 内の `self.current_port = 5004` を変更。
  - 画質・フレームレートを調整したい場合: `generate_frames()` 内の `time.sleep(0.033)` や JPEGエンコード品質数値を変更。

### ④ `frontend/index.html` （Web画面構造）
- **機能**: Single Page Application (SPA) 構造のHTML。サイドバー（カメラ一覧・プリセット・制御ボタン）、メイン画面（映像プレビュー・ROI設定・ネットワーク設定・詳細レジスタ）、再起動モーダルなどを定義。
- **よくある修正ポイント**:
  - 画面の項目名やテキストを変更したい場合: 該当する `<label>` や `<h3>` などのテキストを直接編集。
  - タブを増やしたい場合: `<nav class="tab-nav">` にボタンを追加し、`<div class="tab-panel">` を追加。

### ⑤ `frontend/style.css` （デザイン・スタイル）
- **機能**: 産業用機器向けのダークテーマデザイン、カードレイアウト、アニメーション、レスポンシブ対応。
- **よくある修正ポイント**:
  - カラーテーマを変更したい場合: 先頭の `:root` セレクタ内の `--color-accent` や `--color-bg-base` などのカラーコードを変更。
  - ボタンやパネルの大きさを変えたい場合: 各セレクタの `padding` や `border-radius` を調整。

### ⑥ `frontend/app.js` （画面ロジック）
- **機能**: ブラウザ上の操作イベント、Flask API との通信（`fetch`）、スライダーと数値の同期、`localStorage` による設定プリセット保存・読込、再起動催促ダイアログの制御など。
- **よくある修正ポイント**:
  - プリセットの保存先や初期値を変更したい場合: `captureCurrentSettings()` や `applySettingsToForm()` を修正。
  - デフォルトの解像度・FPSプリセット値を変更したい場合: `initPresets()` を修正。

## 4. カメラの動作モード（Start / Stop / Restart）の意味

| ボタン | コマンド (`occ.exe`) | 意味・役割 |
|---|---|---|
| **▶ 配信開始** | `-m start` | カメラ内部のRTPストリーミング配信を開始し、映像パケットの送信を始めます。 |
| **⏹ 配信停止** | `-m stop` | 映像パケットの送信を停止し、カメラを省電力/スタンバイ状態にします。 |
| **🔄 再起動** | `-m restart` | カメラ本体のマイコン・プロセッサをソフトリブートします。**設定変更を反映させるために必須です。** |

## 5. トラブルシューティング

1. **画面に「occ.exe が見つかりません」と出る**
   → `backend/` フォルダの中に `occ.exe` が正しく配置されているか確認してください。
2. **カメラが見つからない (スキャン結果が0台)**
   → PCとカメラが同一のネットワーク（例: 192.168.2.xxx）にあるか、LANケーブルが接続されているか、Windows Defender ファイアウォールでブロックされていないか確認してください。
3. **映像が表示されない**
   → カメラ側の「RTP 送信先 IP」が「このPCのIPアドレス」になっているか、ポートが「5004」になっているか確認し、カメラを再起動してから「配信開始」を押してください。
